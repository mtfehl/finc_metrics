Asymmetric Volatility

Leverage effect, TARCH, and EGARCH models
Author

Michael Fehl

Published

March 3, 2026

The Leverage Effect

In a standard GARCH model, only the size of a past return matters for future volatility. \(Z_{t-1}^2\) appears in the variance equation, so positive and negative shocks of the same magnitude have identical effects.

Empirically this is not the case. Negative returns increase volatility more than positive returns of the same size. This is the leverage effect.

The economic rationale: a negative return decreases the firm’s equity value. If debt is fixed, the leverage ratio (debt/equity) rises, making the firm riskier. So bad news raises the risk premium demanded by investors, and volatility spikes.

Implication: volatility dynamics are asymmetric. The variance responds differently to positive and negative shocks.

Diagnosing Asymmetry: Engle-Ng Tests

Before fitting an asymmetric model, test for asymmetric behavior using the Negative Sign and Negative Size Bias tests (Engle and Ng, 1993).

Let \(\hat{c}_t^2 = Z_t^2 / \hat{\sigma}_t^2\) be the squared standardized residuals from a fitted GARCH model.

Negative Sign Test: regress \(\hat{c}_t^2\) on an indicator for the previous return being negative:

\[\hat{c}_t^2 = c_0 + c_1 \mathbb{1}_{(r_{t-1} < 0)} + u_t\]

\(H_0\): \(c_1 = 0\) (sign doesn’t matter). Reject if \(c_1\) is significant: negative returns yesterday are associated with larger residual variance today.

Negative Size Bias Test: regress on the magnitude of negative shocks:

\[\hat{c}_t^2 = c_0 + c_1 r_{t-1} \mathbb{1}_{(r_{t-1} < 0)} + u_t\]

Both are simple t-tests. If the correctly specified model leaves no sign/size bias, these tests should be insignificant on the standardized residuals.

library(rugarch)
set.seed(9)

# simulate GARCH data with leverage (TARCH-style)
n <- 600
z <- numeric(n); sig2 <- numeric(n)
omega <- 0.0001; alpha <- 0.05; gamma <- 0.10; beta <- 0.85

sig2[1] <- omega / (1 - alpha - gamma/2 - beta)
z[1]    <- sqrt(sig2[1]) * rnorm(1)
for (t in 2:n) {
  ind     <- as.numeric(z[t-1] < 0)
  sig2[t] <- omega + alpha * z[t-1]^2 + gamma * z[t-1]^2 * ind + beta * sig2[t-1]
  z[t]    <- sqrt(sig2[t]) * rnorm(1)
}

# fit symmetric GARCH first
spec_g <- ugarchspec(
  variance.model     = list(model = "sGARCH", garchOrder = c(1, 1)),
  mean.model         = list(armaOrder = c(0, 0), include.mean = FALSE),
  distribution.model = "norm"
)
fit_g <- ugarchfit(spec_g, data = z)
c2    <- residuals(fit_g, standardize = TRUE)^2
r_lag <- z[-n]
neg   <- as.numeric(r_lag < 0)

# negative sign test
sign_test <- lm(c2[-1] ~ neg)
summary(sign_test)$coefficients

TARCH (GJR-GARCH)

Threshold ARCH (Zakoian, 1993; Glosten, Jagannathan, Runkle, 1993). The variance equation adds a term that activates only when the previous shock is negative:

\[\sigma_t^2 = \omega + \alpha Z_{t-1}^2 + \gamma Z_{t-1}^2 \mathbb{1}_{(Z_{t-1} < 0)} + \beta \sigma_{t-1}^2\]

Equivalently:

\[\sigma_t^2 = \begin{cases} \omega + \alpha Z_{t-1}^2 + \beta \sigma_{t-1}^2 & Z_{t-1} \geq 0 \\ \omega + (\alpha + \gamma) Z_{t-1}^2 + \beta \sigma_{t-1}^2 & Z_{t-1} < 0 \end{cases}\]

Constraints: \(\omega, \alpha, \beta > 0\), \(\alpha + \gamma/2 + \beta < 1\) (stationarity).

  • \(\gamma > 0\): negative shocks increase volatility more than positive ones (leverage effect)
  • Persistence: \(\alpha + \gamma/2 + \beta\)
  • Unconditional variance: \(\sigma^2 = \omega / (1 - \alpha - \gamma/2 - \beta)\)

k-step ahead forecast:

\[\sigma_{T+k|T}^2 = \sigma^2 + (\alpha + \gamma/2 + \beta)^{k-1}(\sigma_{T+1|T}^2 - \sigma^2)\]

spec_t <- ugarchspec(
  variance.model     = list(model = "gjrGARCH", garchOrder = c(1, 1)),
  mean.model         = list(armaOrder = c(0, 0), include.mean = FALSE),
  distribution.model = "norm"
)

fit_t <- ugarchfit(spec_t, data = z)

EGARCH

Exponential GARCH (Nelson, 1991). Instead of modeling \(\sigma_t^2\) directly, EGARCH models \(\log \sigma_t^2\):

\[\log \sigma_t^2 = \omega + \alpha\left(\left|\frac{Z_{t-1}}{\sigma_{t-1}}\right| - m\right) + \gamma \frac{Z_{t-1}}{\sigma_{t-1}} + \beta \log \sigma_{t-1}^2\]

where \(m = E(|\epsilon_t|)\) (for normal innovations, \(m = \sqrt{2/\pi}\)). Persistence is \(\beta \in (0,1)\).

Key features: - No non-negativity constraints needed: \(\log \sigma_t^2\) can take any value, so \(\omega\) does not need to be positive - Asymmetry via \(\gamma\): if \(\gamma < 0\), negative shocks (\(Z_{t-1}/\sigma_{t-1} < 0\)) increase \(\log \sigma_t^2\) more than positive ones - The \(|\cdot| - m\) term captures the size effect; the \(\gamma\) term captures the sign effect

spec_e <- ugarchspec(
  variance.model     = list(model = "eGARCH", garchOrder = c(1, 1)),
  mean.model         = list(armaOrder = c(0, 0), include.mean = FALSE),
  distribution.model = "norm"
)

fit_e <- ugarchfit(spec_e, data = z)

For assets exhibiting asymmetric dynamics (most equities), TARCH or EGARCH will outperform the symmetric GARCH. Exchange rate returns typically do not exhibit asymmetry, so a standard GARCH often suffices there.

In practice, TARCH(1,1) is often found to be one of the most successfully forecasting specifications for equity returns.
